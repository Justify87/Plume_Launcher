# Plume Launcher Advanced changelog

This is the release history of **Plume Launcher Advanced**, maintained separately
from the original Plume Launcher. Older Plume and Classic/Overview notes remain available in the Git history
before the repository cleanup; they are not current release notes.

The launcher displays release notes from the section matching its `versionName`.
Keep the most important six changes first and use one `- ` bullet per change.

## Unreleased

- **Repository maintenance.** Remove obsolete archival documents, an unpublished upstream web site, historical screenshots, a dead helper and unused resources while preserving active media and VPN contracts.
- **Expressive TV redesign.** Replace the old V-Design home grid with the user's new 1536×864 reference composition.
- **One-line upcoming shelf.** Show six upcoming items with date badges and spatial D-Pad navigation.
- **Compact settings.** Refresh launcher settings and all Mullvad TV pages with dark matte cards, lime focus and subtle transitions.
- **Accessible shortcuts.** Add visible All Apps and installed Spotify shortcuts to the icon sidebar.
- **Flexible UI tooling.** Retire outdated Plume design restrictions; maintained UI dependencies are permitted after review.
- **Preserve Mullvad behavior.** Keep original account, relay, DNS, split-tunneling and service integrations.

## 0.1.0

- **First Advanced release.** Start independent versioning for Plume Launcher Advanced.
- **V-Design Home.** Navigate one modern Android TV home screen with the remote.
- **Nuvio TV.** Show in-progress, newly available and upcoming episodes from supported TV channels.
- **Real media data.** Hide unavailable sections instead of showing sample content.
- **Integrated Mullvad VPN.** Open the TV VPN interface in the same ARM64 Android app.
- **Shield TV support.** Use Android TV Home navigation, app shortcuts and system access.
- **Pinned toolchain.** Build and validate the combined Plume-Mullvad APK.
- **GitHub updates.** Get future stable releases from this fork.
